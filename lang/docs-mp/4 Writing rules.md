## 4.1 Main writing rules
* If a peripheral vowel precedes a liquid, nasal, or, in some contexts, an alveolopalatal, dentialveolar, or velar consonant, then it is not marked but pronounced as peripheral
	* *suyet* `1SG-BEN`
	* *sanin* `3SG.F-PER`
	* *tetezunun* `hand-2SG.POSS-INSTR`
* *a* does not follow this role, so *san* is still [san] and not [sæn], though in some cases, *a* will be pronounced [æ] because it follows this rule but remains unmarked in especially casual speech
