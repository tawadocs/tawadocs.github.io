## 1.2 Vowel inventory
|               | Front | Near-front | Central | Near-back | Back |
| ------------- | ----- | ---------- | ------- | --------- | ---- |
| **High**      | i ĩ  |            |         |           | u ũ |
| **Near-high** |       | ɪ          |         | ʊ         |      |
| **Mid**       | e ẽ  |            | ə       |           | o õ |
| **Low-mid**   |       | ɛ          |         | ʌ         |      |
| **Near-low**  | æ     |            |         |           | ɔ    |
| **Low**       |       |            | a ã    |           |      |
* Vowels are split into these groups:
	* Regular: *a i u e o*
	* Nasal: *ą į ų ę ǫ*
	* Peripheral: *á í ú é ó*
	* Neutral: *à ù*

## 1.3 Allophones
| Phoneme | Allophone | Condition                 |
| ------- | --------- | ------------------------- |
| nʲ      | ɲ         | /ɲ/ in consonant clusters |
| n       | ɲ         | /ɲ/ before [i ĩ ɪ]       |
| n       | ŋ         | /ŋ/ before velars         |
| h       | j̊        | /j̊/ before [i ĩ ɪ]      |
| h       | ɸ         | [ɸ] before [u ũ]         |
* *n* [n] changes into *m* [m] before bilabials (e.g., *hon* + *ppu* -> *homppu*)
