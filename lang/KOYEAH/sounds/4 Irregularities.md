## 4.1 Consonants
* Note that some consonants have many variants due to dialects or speaker:
	* *mg* :: `/m͡ŋ~m͡g~ʘ͡ŋ/`
		* yes, that is a click!
		* in some Tawish dialects, *mg* is actually a bilabial click (prominent) coarticulated with the velar nasal
		* in NSKT, it is simply `/m͡ŋ/`
	* *N* :: `/ɴ~ɢ~q/`
		* it is written as: *hg*, *h*, or *nq*
		* it is pronounced `/ãõ̯/` if written as *nq*
			* note that the pronunciation of this diphthong varies speaker-to-speaker
			* some pronounce it in one beat (so it is one mora), whereas others may pronounce it as two morae:
				* `/ã.õ̯/`
				* in NSKT, this diphthong (the only diphthong in Tawa) is usually one mora

### 4.1.1 More on the uvular nasal
* If *nq* is in a non-word-final position, it becomes a bare vowel sequence and loses its gliding property, pronounced only as:
	* `/ã.õ/`
* So:
	* *Nqoro* is `/'ã.õ.'o.ɺo/`
		* note that the /ã.õ/ sequence either gets **no stress** or whatever follows it gets stressed again
		* so both are valid:
			* `/ã.õ.'o.ɺo/`
			* `/'ã.õ.'o.ɺo/`
* But in word-final positions, for example:
	* *Kamunq* is `/'ka.mu.'ãõ̯/`~`/'ka.mu.'ã.õ̯/`
* As the uvular nasal, it is written as *h* or *hg*
* These are the rules:
	* before the vowel **/u/**
		* use *h*
	* non-word-final position
		* use *hg*
	* word-final position
		* use *h* (it becomes a diphthong again)
* So:
	* *Hgopo* is `/'ɴo.po/`
	* *Hupo* is `/'ɴu.po/`
	* *Pohuhgo* is `/'po.ɴu.ɴo/`
* The *h-final* ending is realised as the diphthong `/ãõ̯~ã.õ̯/` though:
	* *Iah* :: `/'i.a.'ãõ̯/~/'i.a.'ã.õ̯/`
* At the end of consonants, the semantic inverser uses the *ã* form:
	* *Honã* :: `/'hɔ.'nãõ̯/~/'hɔ.'nã.õ̯/`
* Monomoraic words take *ã*:
	* *Huã* :: `/'ɴu.'ãõ̯/~/'ɴu.'ã.õ̯/`
	* *Uã* :: `/'u.ãõ̯/~/'u.'ã.õ̯/`
* Before any **h**-syllable, *ã* is used:
	* *Hhuã* :: `/'ɴ.ɴu.'ãõ̯/~/'ɴ.ɴu.'ã.õ̯/`
	* *Kohaã* :: `/'ko.ha.'ãõ̯/~/'ko.ha.'ã.õ̯/`

### 4.1.2 The Tawish diphthong
* All of this also explains why Tawa only has one, singular diphthong
* The diphthong comes from the uvular nasal itself, as the nasal was vocalised
