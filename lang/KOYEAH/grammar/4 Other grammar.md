## 4.1 **Ashi Tawa** and **Koyeah Tawa**
* *Ashi Tawa* (Modern Tawa) and *Koyeah Tawa* are registers of the same language, *Sowãnqku Tawa* (Southern Tawa)
* Koyeah Tawa's grammar is the same as Ashi Tawa's, except for some differences at the fundamental level, which have been listed in:
	* **1 Register basics**
	* **2 Cases**
	* **3 Pronouns and topic**
* This means that Koyeah Tawa has the same *similative family* (imo, im, imnyi...), the same *Actor-Undergoer distinction*, and even the same *clausal features*:
	* **honeu haha** -> `person-REL.COP funny`
		* "The person that is funny"
	* **so′o korunai** -> `3SG.M-U die.V-IV`
		* "He died"

## 4.2 What **Koyeah Tawa** lacks
* Koyeah Tawa primarily lacks:
	* *advanced aspect*
		* it only has: **tohi/toppu** and **rehi/reppu**
		* aspect are unbound morphemes in Koyeah Tawa:
			* *su kamu myo atora tohi* -> `1SG eat.V QNT apple PFV-BACK`
				* "I ate many apples"
	* *articles*
	* *plural articles*
	* *augmentative-superlatives*
		* it only uses reduplication
			* **ii** (good) -> **ii'ii** (best)
			* **kanata** (happy) -> **kakanata** (happiest)
		* it does retain *ie*, *sta*, and *ol*:
			* **olii** -> too good
			* **iista** -> least good
			* **ieii** -> better / (more) good / pretty good / decent
	* *vocatives*
		* only the interjection *à* or word *waka* are used for calling
	* *platonic-romantic distinctions*
	* *advanced mood*
		* there is only one imperative **ake** and one request **fuka** marker
		* the assertion or emphatic particle **ya** is retained
		* grammaticalised evidentiality (**ipappu** / **ipa-**), desideratives (**atai**), and optatives (**are**) remain
		* only one way to ask questions, it is by adding *no?* to the end
	* *modal particles*
		* the modal particle *ũ* has been turned into an infinitive *te* here
		* *te* functions the same as the English **to** in terms of modifying verbs, like in *kitate riwaka* (like **to** think)
	* *noun-compounding marker*
		* **ce** does not exist
	* *advanced conditionality particles*
		* there is only **shi** to mark context
		* both *irreal verbs* and *irreal nouns* have been pruned
			* e.g., you'd say *ieiite kamu* -> `AUG-good-INF eat.V`
				* "better to eat"
				* ~"I should eat"
		* cases or other particles can specify the type of context (no **zhi/shi** distinction)
			* do note that the entire relationship system, apart from **zhi**, is intact (e.g., **ze**, **ho**, etc.)
