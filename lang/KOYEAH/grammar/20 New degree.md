| -------- | --------- | ------------- |

| **uo**   | `/uo/`    | **SUP.POL**   |

| **suta** | `/su̥ta/` | **DIM.PEJ**   |

## 20.2 Changes
* The degree machinery is the same, except a few differences:
	* a lot of these are prefixes now:
		* *uochi* :: sea
		* *uoii* :: best
* Note that *suta* remains a suffix:
	* *kamusuta* :: to eat too little
		* implies that whatever you ate might have been enough, but it wouldn't have hurt or would've been better to eat more
	* *kamunesuta* :: to not eat enough
		* implies that you were unable to sufficiently satiate yourself

### 20.2.1 Difference of *io* vs. *uo*
* *uo* is masculine/polite
* *io* is feminine, and also affectionate/cute
* Depending on gender:
	* females use *io*, and men use *uo* (generally)
		* depending on context, females could use *io* to sound rough or tough
		* men could use *io* in affectionate settings, but in the wrong contexts, a man using *io* can be derogatory, rude, crass, or immature
* Formally:
	* in words like *uochi* (sea), you use *uo-*, not *io*
	* you'll see that even in formal sermons or oaths, females will tend to use *io*
	* but in technical manuals, *uo-* would still be used
	* so it depends on grammar (for abstract/neutral concepts), context (spoken or written formality), etc.

## 20.3 Word types
### 20.3.1 Superlatives
* **Verbs**
	* *Uokamu* :: to eat the most
	* *Uohateru* :: to run the most
* **Modifiers**
	* *Uokami* :: the most edible
	* *Uohaterinu* :: the most swift
* **Property**
	* *Uoasabu* :: the most house-like
* **Nouns**
	* *Uochi* :: a sea

### 20.3.2 Diminutives
* **Verbs**
	* *Iukamu* :: to eat the least
	* *Kamusuta* :: to eat unhealthily (too little)
	* *Iuhateru* :: to run the least
	* *Haterusuta* :: an unhealthy amount of not running
		* e.g., sedentarism (*haterensuchina* or *haterensuchinta*)
			* note that *suta* drops the *-a-* when inflecting sometimes
			* before /i/ and /u/, it becomes *such-*
			* *haterensuchinta* is the label for the medical condition (sedentarism), as in a disorder, whereas *haterensuchina* doesn't carry much weight (more informal way, like something you'd call a lazy friend)
* **Modifiers**
	* *Iukami* :: the least edible
	* *Kamisuta* :: inesculent, (food) fit for the dogs
	* *Iuhateri* :: least swift
	* *Haterisuta* :: sluggish, snail-paced
		* as explicit adverbs, they may take the *-isutanu* form (e.g., *haterisutanu*)
* **Property**
	* *Iuasabu* :: the least like a house
	* *Asasutabu* :: a slum house
* **Nouns**
	* *Iuchi* :: a drop, a trickle
	* *Chisuta* :: piss-weak

### 20.3.3 Excess
* **Verbs**
	* *Okamu* :: eat too much
* **Modifiers**
	* *Okami* :: way too edible (too good)
* **Property**
	* *Oasabu* :: way too much like a house (e.g., too comfortable, too good)
* **Nouns**
	* *Ochi* :: the ocean

### 20.3.4 Limitations
* *Uoasa* :: could mean a villa but it would depend on context
	* such constructions are therefore best avoided
* Don't try to apply it on all roots
* Because, *uoasa* is like saying 'most house,' which is hard to interpret
* *Uochi*, though, is like saying 'most water,' which can refer to the sea

### 20.3.5 Negation and connotation
* **Negation of excess**
	* *Onechi* :: not an excess of water / not an ocean
	* *Oneasabu* :: not too much like a house (e.g., not too comfy)
		* has a 'not to the extent I was expecting' implication
	* *Onekami* :: not too edible
		* same implication ('not as edible as I had thought it would be')
	* *Onekamu* :: to not eat too much
		* someone on a diet or intentionally stopping themselves from eating (too much)
* **Negation of diminutives**
	* *Iunechi* :: not even a single inkling of water
	* *Iuneasabu* :: not like a house in the slightest (e.g., a literal warzone)
	* *Iunekami* :: not edible in any way whatsoever
	* *Iunekamu* :: fasting / not eating at the least
	* *Chinesuta* :: literally no water, an atom of water
	* *Asabunesuta* :: not even like the slums, in which one can at least survive
	* *Kaminesuta* :: regurgitate
		* *kaminesuta* refers to food so bad and inedible that it's like regurgitated vomit
	* *Kamunesuta* :: unhealthy avoidance of all food
* **Negation of superlatives**
	* *Uonechi* :: not too much, not too little
	* *Uoneasabu* :: an okay house (middle-class)
	* *Uonekami* :: eatable, at least
	* *Uonekamu* :: to eat enough to survive
* **Negation of augmentatives**
	* *Ienechi* :: not enough water
	* *Ieneasabu* :: not enough house-like
	* *Ienekami* :: not edible enough / not good enough
	* *Ienekamu* :: eating insufficiently

## 20.4 Augmentatives
* *ie* is an augmentative and relative comparative:
	* *Ieii* :: pretty good / better / quite good
	* *Ieiite kamu* :: better to eat / shouldn't (we) eat
		* or, another conversational variant:
			* *kameneoi ni ii ine anee yo?*
				* lit. "As for our (irreal) eating, good is not?"
				* ~"Wouldn't it be better if we went out to eat?"
* Use *mo* in comparisons:
	* *Sonōe mo ii* :: better than him
	* *Sano ni sonōe mo kitai ue* :: I like her more than him
	* *Ryo asa ni shiou asa mo ii* :: this house is better than that house
	* *Hateren ni kamen mo hateri ue* :: it is faster to run than it is to eat
* Chaining 'she is better than the bird that is smaller:'
	* *Sano ni ielilii ngoshi mo ii* :: she is better than the smaller bird

## 20.5 Similatives
* Use:
	* *insuta* :: barely like
	* *imomg* :: not like
	* *imin* :: absolutely nothing like
	* *uoimo* :: the same as
* Examples:
	* *zunōe insuta* :: barely like you
	* *zunōe imomg* :: not like you
	* *zunōe imin* :: absolutely nothing like you
	* *uoimo* :: the same as you

## 20.6 Other degrees and connotation
* Absolute: *uo/io*
* Least: *suta/iu*
* Excess: *o*
* Relative/augmentative: *ie*
* Examples:
	* *Ielilii ii* :: slightly better
		* *ielilii iita*
			* slightly better (in a bad way)
	* *Ieii* :: better / more good
	* *Iepokii ii* :: significantly better
		* *iepokiita ii*
			* 'too good' / it is so good that it's bad
* Or just use modifiers:
	* *Uzumi ii* :: far too good
		* and with connotation:
			* *uzumita ii* :: far too good (for its own sake)
			* though *uzuntai* is fine, *-tai* is no longer used
			* so, you always say *uzumita* over *uzuntai*
			* all modifier particles **always** go **before** the connotations (including both *ta* and *oi*)
* Also you can't say:
	* *iukamu fuka!*
* ... to mean 'have a bite'
* You'd say:
	* *Lilii kamu, fuka!*
		* lit. "littleish eat, please!"
		* ~"eat a little! / have a bite!"

## 20.7 Intensives
* Reduplicate the first unit (CV, VV, VC(V)):
	* *Lilii* :: a little
	* *Lililii* :: very little
	* *Pokii* :: big
	* *Popokii* :: very big

## 20.8 Connotation augmentatives
* Use connotation on the root:
	* *Iepokiita* :: pretty fat / relatively fat
	* *Iepokiioi* :: quite healthy / a little large

## 20.8 Moderatives
* Use *-bu*:
	* *Ebu* :: kind of good / goodish
	* *Kambu* :: edible-ish
	* *Asabu* :: kind of a house / house-ish
* Or *enu*:
	* *Enu ii* :: it is good / kind of good
	* *Enu ushikitsu* :: it was alright (in terms of fun) / it was decently fun
	* *Enu koibwuen* :: it was fairly boring

## 20.9 Dynamic degree
* Simply use an adverbial phrase:
	* *Subeki wanōe do ieii ou yara* :: `every.ATTR time-N.ACC PER AUG-good ACC2 become`
		* lit. "Every time through better become"
		* ~"It is becoming better by the hour"
* Or use modifiers like gradually:
	* *Ieii ou safuki yara* :: `AUG-good ACC2 gradual-ATTR become`
		* ~"It gets better and better"

## 20.10 Certain structures
* Some structures, like the 'the more X, the more Y,' may or may not use degree, or they may use it in a weird way, even though one might believe otherwise:
	* *Hiouinu kamu, reopokii ue* :: `DEM.DIST.ABST-ATTR-MOD eat.V IPFV-big-ATTR COP.POL`
		* lit. "That-ly eat, will big is"
		* ~"If you eat in that way, you'll become fatter"
	* *Hiou euma da kamen reopokii ue* :: `DEM.DIST.ABST extent ALL eat.GER IPFV-big-ATTR COP.POL`
		* ~"If you keep on eating, you'll keep on getting fatter"
* Or, here's one without *hiou / euma*:
	* *Wam butei ou jijiinu tonampanguu zhi arenki no o angarenebuyarae* :: `one.ORD PROP-N.PAT ACC2 INTENS~LOC-ATTR-MOD PFV-number-SRC.LEX\V TEMP other.ATTR NMZ U PRIV-different-PROP-become.MID.POL`
		* lit. "One property exactly was measured when (it was), the other one indistinctifies"
		* ~"When you measure one property accurately, the other property becomes less accurate to measure"
			* note: *tonampanguru* should be the proper verb form, but *tonampanguu* is fine as a shorthand
			* *-yarae* is formed from *yaro* (to become) + *-(n)ae* (polite middle voice)
