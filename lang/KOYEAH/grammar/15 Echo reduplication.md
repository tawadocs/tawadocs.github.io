## 15.1 Simple palatalisation rule
- **D + i** -> **Ji**
- **T + i** -> **Chi**

## 15.2 Generalisation

**Marker:** **P-** (Backup: **M-**)
- **Kitei** -> **Kitei pitei** (Things and such)
- **Irime** -> **Irime pirime** (Work and whatever)
- **Pamu** -> **Pamu mamu** (Snacking/nibbling)
	- *p* to *m*

## 15.2 Pejorative
| **Root**      | **Reduplicated Form** | **Notes**                        |
| ------------- | --------------------- | -------------------------------- |
| **Kamōe**     | **Kamōe damōe**       | Food and crap!                   |
| **Ii** (Good) | **ii jii**            | _D + i_ becomes **Jii**          |
| **Irime**     | **Irime jirime**      | _D + i(rime)_ becomes **Jirime** |
| **Dasi**      | **Dasi sasi**         | **S** backup                     |
| **Taki**      | **Taki daki**         | -                                |
* Marker: **d[ə]-** (Backup: **s[ə]-**)
* For **i**, *j* will be used, so:
	* *ii jii*, *irime jirime*
		* *ii jii* is like saying 'yeah, "good," sure'
		* *irime jirime* means 'work and all that bullcrap'
* **i** is the only case where the vowel remains the same
* So if the vowel is not **i**, like *ga*, then:
	* *ga da*
	* *ai dai*
	* *ainawa dainawa*
	* *aiu daiu*
	* *ba da*
	* *bobo dabo*
	* *de se*

## 15.3 Examples
| **Word Type**       | **Root** | **Generaliser (P/M)** | **Pejorative (D/S)**        |
| ------------------- | -------- | --------------------- | --------------------------- |
| **Standard**        | _Kanu_   | Kanu **p**anu         | Kanu **d[ə]**nu             |
| **Vowel-Initial**   | _Ume_    | Ume **p**ume          | Ume **d[ə]**me              |
| **High Vowel (i)**  | _Ichie_  | Ichie **p**ichie      | Ichie **j[ə]**chie (D -> J) |
| **P-Initial**       | _Pone_   | Pone **m**one         | Pone **d[ə]**ne             |
| **D-Initial**       | _Dako_   | Dako **p**ako         | Dako **s[ə]**ko             |
| **T-Initial (Chi)** | _Chita_  | Chita **p**ita        | Chita **ch[ə]**ta           |
* The schwa isn't marked, so just writing *pone dane* is fine
* For the pejorative, both the consonant and vowel changes:
	* *kamu* -> *pamu* /pəmu/
	* *kitei* -> *patei* /pətei/
	* ... etc.

## 15.4 Semantic pairing
- **Kamen chihaien** (Eating + Drinking = Dining/Meals)
	- _Eanaite kamen chihaien._
		- ~"We went out for dining"
		- ~"We went out to eat a meal"
- **Irimen asahaien** (Working + Residing = Lifestyle/Living)
- **Harinaien eanaien** (Buying + Going = Running errands/Shopping)
