## 18.1 Universal marker *no*
* It is used to ask questions:
	* *Ue* :: it is
		* *Ue no?* :: is it?
* Casually, it is dropped in favour of a rising intonation:
	* *Ryo i* :: it is this
		* *Ryo?* :: this?
* *yo* is just a more polite and sometimes more intimate particle (depending on context)
* *no* can be casual and informal, especially in non-polar questions or questions that use any *oto(-)* particle
* Still, you'd use *yo* for softness, politeness, and intimacy (depending on context)
	* so if you're talking to an elder or a boss or a stranger, *yo* is the one you need
* For friends or non-strangers, *no* can be fine, but it depends on context
* For nominalised questions, *no yo* is used (and it can't be harshened)
* If you want a harsh nominalised question, end it with *ng (e)*
	* it creates a 'huh? / you think so? / yeah? / come on! / try me! / bite me!' tone
	* there is a tone on it too
	* with the *e* (as *ng e?*), it makes it more condescending, like saying 'bring it on, (OK?)!' but approximating it to 'bring it on' is bad
	* you'd never use it with a friend challenging you to a duel in, say, a game, because it would be rude and harsh
	* you'd say: *ake ete yaranai, lilii nigo ana!*
		* ~"(It is) okay to come, little cat, (you know?)"
		* ~"Why? Are you afraid? Bring it on!"
	* or even: *ake yaranai ana!*
		* ~"Come (then)!"
		* ~"Come!"
		* but it captures the 'bring it on / bite me' nuance
* Note that you can ask a question about a topic like this:
	* *Sano ni no/yo?* :: who is she?
		* *yo?* would make it more polite and soft, whereas *no?* would be casual
		* also, due to the genderlectical differences, males cannot just say *sano ni?*, even though dropping question particles is a common occurrence in Tawa
			* this is because *ni* is also a feminine sentence-final particle and softener
			* men using it could be cringe and even derogatory
		* a female could say *sano ni?* though
		* this difference is covered in Ashi Tawa's grammar

## 18.2 **Wh-** interrogatives
| English | Tawa                    |
| ------- | ----------------------- |
| Who     | **otohon**              |
| What    | **otōe** / **fuyu**    |
| Where   | **otoji**               |
| When    | **otowanō**            |
| Why     | **ototan** / **otodan** |
| Which   | **ochi (X)**            |
| How     | **otoun**               |
* These are formed with *oto*
* *oto no* is often casually contracted as *otono*

### 18.2.1 Polar
* Statement + no?
	* *Kamu no?*
		* ~"Will you eat?"

### 18.2.2 Content questions
* The question word goes exactly where your answer would sit
	* *Nama ni otōe ue no?*
		* ~"What is your name?"

### 18.2.3 Choice questions
* *oto* is added after each choice given:
	* *Atora ue oto, arenki ba ue oto no?*
		* ~"Is it an apple or is it just another sweet fruit?"
		* note: you'd write *otono?* casually (contraction)
* or *ato* is used:
	* *Atora ue ato arenki ba no?*
		* ~"Is it an apple or is it just another sweet fruit?"
* Difference between *oto* and *ato*:
	* *ato* is a literal 'or' and gives you choices
	* it is used in formal contexts, like sermons, speeches, or examinations

### 18.2.4 Explanatory questions
* To seek an explanation, you use *ue ototan no?*
* Note that *ototan no* is almost always as *ototano*
	* *Makuen ototan no?*
		* ~"Why are (you) crying?"
		* ~"For what reason are you crying?"
* You usually use *otoun* to ask the 'how:'
	* *Otoun makuen ototan yo?*
		* ~"Why is it that you are crying?"
		* *yo* is much softer as an interrogative than *no*

### 18.2.5 Rhetorical & softened questions
* Questions can be used to make suggestions or show doubt
* *yo* is used for this
	* *Eanarra yo?*
		* ~"Won't you go?"
		* ~"Let's go"
* *oto* + pronominal + *yo/no* for doubt
* mostly *yo* is used; *no* is often rude in these constructions, unless addressing yourself
	* *Reosoramanai, otsu no?*
		* ~"I'm so silly, I don't even know if it will rain or not"
	* *Reosoramanai otsu yo?*
		* ~"I'm unsure if it will rain"
		* ~"I wonder if it will rain"
	* *Reosoramanai, odzu yo?*
		* ~"Do you wonder if it will rain?"
		* ~"Do you think that it will rain?"
		* ~"Do you doubt it will rain?"
	* *Reosoramanai otona yo?*
		* ~"Do we think that it is going to rain?"
	* *Fui reosoramanai odza ya no!?*
		* ~"Do all of you (idiots) genuinely think it is going to rain?"
			* you might say this if it's sunny outside!
* Here's a playful example:
	* *Atora ni otoun mafi odzu yo?* :: `apple TOP WH-INSTR red.ATTR WH.2SG Q2`
		* ~"Why do you think that apples are red?"
			* it feels like a playful invitation to a riddle
			* *odzu yo?* is quite soft
* If you said:
	* *Atora ni otoun mafi odzu no?*
		* ~"Idiot, why are apples red then?"
		* ~"Do you seriously believe apples are red?"
* Which isn't very playful after all!

#### 18.2.5.1 Pronominal questions
* Use the format:
	* `oto + Q.pron + postp.`
* ... for directing a question with doubt
* For example:
	* *Eanai odzu-ji yo?* :: `MOV-MID WH.2SG-LOC Q.POL`
		* lit. "Being gone you in?"
		* ~"Aren't you wondering where we're headed?"
		* ~"Do you want to guess where we're going?"
		* ~"I bet you don't know where we're going!"
			* depending on tone, particles, etc., that base statement yields a lot
	* *Eanai otona-ji yo?*
		* ~"Where do we want to go?"
		* ~"Where do we think that we will be going"
	* *Eanai otsu-ji yo?*
		* ~"I wonder where I'm going..."
	* *Eanai odza-ji yo?*
		* ~"Do all of you doubt where we are going?"
* With *no*, it would be harshened:
	* *Eanai odza-ji no?!*
		* ~"Do all of you even know where we are going?"
		* ~"Do you all have any idea where we are headed?"
			* something a teacher might say to kids goofing around during a trip to a factory

## 18.4 Asking different types of questions
* Method
	* *Otounte eanarra yo?* :: `WH-INSTR-INF MOV-MID.NEG Q2`
		* ~"How do I get there?"
* State/opinion
	* *Kanteisan ni otoun ue yo?* :: `food.N.PAT-3SG.F.POSS TOP WH-INSTR COP.POL Q2`
		* ~"How was her food?"
		* a very polite construction
* Quantity
	* Price: *Otomani ue yo?* :: `WH-money COP.POL Q2`
		* ~"How much is it?"
		* ~"What's the price"
	* Number: *Otomyo subi ue yo?* :: `WH-MANY desire.ATTR COP.POL Q2`
		* lit. "How much is desired (as for you)?"
		* ~"How much do you want?"
		* ~"How many do you want?"
	* Specific time: *otowanō-ji ue yo?* :: `WH-time-LOC COP.POL Q2`
		* ~"What hour/minute is it?"
		* tip:
			* *otosejou* for hours (lit. 'which sixty')
			* *otomi* for minutes (lit. 'which fifth')
			* *otosu* for seconds (lit. 'which first')
			* for maximum specificity, add *-ji*:
				* e.g., *otosejou-ji i no?!* (exactly which hour is it?)
				* here, the *no* paired with the direct *i* copular adds more of a 'tell me!' or 'what do you think, huh?' tone
				* if a mother caught her son awake, this would be something she'd say
	* General time: *otowanō ue yo?* :: `WH-time COP.POL Q2`
		* ~"What hour is it?"
		* tip:
			* specific time uses *otowanō-ji*
			* general time simply uses *otowanō*
			* spelt with a hyphen because these have been lexicalised that way, even though they are postpositional phrases
* Identification
	* What kind: *Kita otobu kanteioe yo?* :: `like WH-PROP food.N.PAT-N.ACC Q2`
		* ~"What kind of food do you prefer?"
	* What happened / was done: *Otofunai yo?* :: `WH-ACT-MID Q2`
		* lit. "What was done?"
		* you'd say it to a friend who was sad
	* What did (someone) do: *Otofu yo?* :: `WH-ACT Q2`
		* lit. "What happened / what did (one) do?"
		* if your friend told you that someone ate raw chicken for challenge, you'd exclaim:
			* *otofu no?!*
		* meaning, 'what the hell (he really did that)?!'
	* What is (it): *Ryo no ni otōe ue yo?* :: `DEM.MED NMZ TOP WH-N.ACC COP.POL Q2`
		* ~"What is this (thing)?"
* Meanings, definitions, etc.
	* How to (do X): *'Chiken' ni otounte fofu Tawa un yo?* :: `chicken TOP WH-INSTR-INF speak.PLATONIC.V tawa INSTR Q2`
		* ~"How do (I) say chicken in Tawa?"
	* What does it mean: *Omoko wou ni otounte shirenai yo?* :: `chicken QUOT3 TOP WH-INSTR-INF know-MID Q2`
		* lit. "As for 'omoko,' how to understand (it)?"
		* ~"What does 'omoko' mean?"
		* this is a highly polite construction
		* casually, you'd say:
			* *omoko wou ni haki otōe no?*
			* lit. "As for 'omoko,' its really what?"
			* ~"What is 'omoko' in reality"
				* you could soften it and/or make it polite with the appropriate particles
* Here is an example of something you'd hear in conversation:
	* *Yoiirekai ue yo?* :: `spirit<good-inner> COP.POL Q2`
		* lit. 'The good inner spirit is?'
		* ~"How are you?"
		* ~"Are you in good spirits?"
			* it would be very sarcastic to someone obviously sad
			* when you don't want to assume state and want to be respectful, you would be indirect:
				* *Riwakaen otōe yo?* :: `think-GER WH-N.ACC Q2`
				* ~"What are you thinking about?"
			* though, the more preferable one would be:
				* *Ng no ue yo?* :: `DUM NMZ COP.POL Q2`
				* lit. "A thing is?"
				* ~"Is a thing there? / what's going on?"
			* or, with people you're closer to (not strangers):
				* *Otōe-otōe ue yo?* :: `DUM NMZ COP.POL Q2`
				* lit. "What-what is?"
				* ~"(Is it) something?"
					* though it just means 'some what is?' or 'is it something?' literally, in Tawa, this is like the English 'what's up'
					* remember that this version is soft (friends and family) and intimate if used with a romantic partner (context disambiguates everything in the end!)
* The simple question words just go at the start or at the appropriate place:
	* *Kamu otoji-un yo?* :: where will we be eating?
	* *Eanate otoji yo?* :: where will we be going?
	* *Haterute otoji yo?* :: where will we be running to?
		* note that the infinitive form (*-te*) is used instead of *ji* for questions like this
		* so, *hateru otoji-ji yo?* is less preferable over *haterute otoji yo?*
		* this rule usually only applies to *otoji*, not other question particles
	* *Ochi no ue yo?* :: which (one/thing) is it?
	* *Nemu otōe yo?* :: what should I choose?
	* *Otowanō, eanai* :: when are we going?
		* *wanō* (and *wanō*-words) and other time words like *ko* don't require *zhi*
	* *Ototan ryo ga iuki nemuoe ue yo?* :: why is this the (most) sound choice?
	* *Ototan ue yo?* :: why is it? / (why) is that (so)?
	* *Ototante nemu genryōe no yo?* :: how do I choose between these things? / by what way do I choose through these things
		* can sound formal
