## 18.1 Universal marker *no*
* It is used to ask questions:
	* *Ue* :: it is
		* *Ue no?* :: is it?
* Casually, it is dropped in favour of a rising intonation:
	* *Ryo i* :: it is this
		* *Ryo?* :: this?

## 18.2 **Wh-** interrogatives
| English | Tawa                    |
| ------- | ----------------------- |
| Who     | **otohon**              |
| What    | **otōe** / **fuyu**    |
| Where   | **otoji**               |
| When    | **otowanō**            |
| Why     | **ototan** / **otodan** |
| Which   | **ochi (X)**            |
| How     | **otoun**               |
* These are formed with *oto*
* *oto no* is often casually contracted as *otono*

### 18.2.1 Polar
* Statement + no?
	* *Kamu no?*
		* ~"Will you eat?"

### 18.2.2 Content questions
* The question word goes exactly where your answer would sit
	* *Nama ni otōe ue no?*
		* ~"What is your name?"

### 18.2.3 Choice questions
* *oto* is added after each choice given:
	* *Atora ue oto, arenki ba ue oto no?*
		* ~"Is it an apple or is it just another sweet fruit?"
		* note: you'd write *otono?* casually (contraction)
* or *ato* is used:
	* *Atora ue ato arenki ba no?*
		* ~"Is it an apple or is it just another sweet fruit?"
* Difference between *oto* and *ato*:
	* *ato* is a literal 'or' and gives you choices
	* it is used in formal contexts, like sermons, speeches, or examinations

### 18.2.4 Explanatory questions
* To seek an explanation, you use *ue ototan no?*
* Note that *ototan no* is almost always as *ototano*
	* *Makuen ototan no?*
		* ~"Why are (you) crying?"
		* ~"For what reason are you crying?"
* You usually use *otoun* to ask the 'how:'
	* *Otoun makuen ototan yo?*
		* ~"Why is it that you are crying?"
		* *yo* is much softer as an interrogative than *no*

### 18.2.5 Rhetorical & softened questions
* Questions can be used to make suggestions or show doubt
* *yo* is used for this
	* *Eanarra yo?*
		* ~"Won't you go?"
		* ~"Let's go"
* *oto* + pronominal + *yo/no* for doubt
* mostly *yo* is used; *no* is often rude in these constructions, unless addressing yourself
	* *Reosoramanai, otsu no?*
		* ~"I'm so silly, I don't even know if it will rain or not"
	* *Reosoramanai otsu yo?*
		* ~"I'm unsure if it will rain"
		* ~"I wonder if it will rain"
	* *Reosoramanai, odzu yo?*
		* ~"Do you wonder if it will rain?"
		* ~"Do you think that it will rain?"
		* ~"Do you doubt it will rain?"
	* *Reosoramanai otona yo?*
		* ~"Do we think that it is going to rain?"
	* *Fui reosoramanai odza ya no!?*
		* ~"Do all of you (idiots) genuinely think it is going to rain?"
			* you might say this if it's sunny outside!
* Here's a playful example:
	* *Atora ni otoun mafi odzu yo?* :: `apple TOP WH-INSTR red.ATTR WH.2SG Q2`
		* ~"Why do you think that apples are red?"
			* it feels like a playful invitation to a riddle
			* *odzu yo?* is quite soft
* If you said:
	* *Atora ni otoun mafi odzu no?*
		* ~"Idiot, why are apples red then?"
		* ~"Do you seriously believe apples are red?"
* Which isn't very playful after all!
