## 19.1 NSKT 3.6
* In NSKT 3.6, negation logic has changed slightly
* These are the copular particles:
	* *Uenane* :: polite middle voice negated copular
	* *Inane* :: casual middle voice negated copular
	* *Ine* :: polite negated copular
		* *uene* is a highly polite and formal negated copular
		* you'd see it in religious texts, holy oaths, sermons, but otherwise not
		* in extremely formal contexts, like with a revered teacher, you may use *uene*
		* we never use *uenenai*, that would be taboo-level vulgar
	* *Irra* :: casual negated copular
* The rude/fighting forms are:
	* *Uerranai*
	* *Irranai*
		* note: explicit rude tone only exists for middle voice forms
		* otherwise, using **-narra** or expletives and whatnot would get your point across, if you cannot use the middle voice form
* And the sarcastic, sardonic, or mocking forms are:
	* *Uenarra*
		* never confuse **uenarra** with **uene** (archaic/literary/formal)
		* **uene** is a non-middle voice negated copular, often substituted for the modern **ine**
	* *Inarra*
* Noun negation examples:
	* *Asa ine* :: "not a house (polite)"
	* *Asa irra* :: "not a house (casual)"
	* *Asa inarra* :: "there isn't any house" (mocking/condescending)
		* you might say this after someone keeps saying there is no house but then it turns out that there was
	* *Asa uenarra* :: "there isn't a house (polite)"
	* *Asa irranai* :: "there isn't a house (casual)"
* For negation of verbs:
	* *-ne* (polite negation)
		* usually almost always used
	* *-rra* (casual negation)
* Examples:
	* *Eanane* :: did not go
	* *Kamune* :: did not eat
	* *Rawane* :: did not sleep
* And casually:
	* *Eanane* :: did not go
		* using *-rranai* would make it impolite or rude
		* for middle voice, you're forced to use *-nane*
	* *Kamurra* :: did not eat
	* *Rawarra* :: did not sleep
* Note:
	* *-narra* ending usually hints at a sarcastic or sardonic tone, sometimes also mocking
	* *-rra* is casual and sometimes direct
		* best avoided, unless talking directly with (especially close) friends, partners, etc.
	* *-rranai* is impolite and rude
		* the middle voice is an exception
		* saying *rranai* makes it rude
	* *-nenai* is sarcastic and sardonic middle voice
		* the sarcastic/sardonic/mocking middle voice is *nenai* (as opposed to the polite *nane*)
* These are the standalone forms:
	* *nē*/*nēn* :: polite negation
		* it still may be too direct (see pragmatics)
		* both forms are fine (*nē*/*nēn*), but they do have a general affect
		* so:
			* *Nē, ryo asa* :: no, this house
			* *Nēn, ryo asa* :: nah (no way), this house
			* *Nēm, baka!* :: hell no, you idiot
			* *Nē, baka!* :: no, dummy!
		* you can see that *nēn* feels more 'emphatic,' sometimes even more formal
		* with words like *baka* (fool), it can alter tone, and therefore interpretation:
			* *nē, baka* :: more playful
				* dummy/silly
			* *nēm, baka* :: a little less playful, more formal
				* idiotic
	* *rra* :: casual/blunt negation
		* this is often rude

## 19.2 Affirmation
* You can affirm by:
	* *seka ue* :: it is that way / so it is / that's right
	* *ii ue* :: that's good / it's fine
		* note that *ii* also appears in constructions like:
			* *zuno ni ii* :: `2SG.AN.POL TOP good`
				* lit. "You are good"
					* but it actually means 'no, you must not' / 'no, you cannot'
					* a friend can use this to strictly tell off another friend from something (without any implication of a joke)
					* it is not light, especially with the omission of a copular
			* *suno ni ii ue* :: `1SG.AN.POL TOP good COP.POL`
				* lit. "I am good"
				* ~"I'm fine, thanks"
				* ~"Thank you, but I'm fine"
		* you do **not** use *ga*:
			* *zuno ga ii* :: `2SG.AN.POL NOM good`
				* lit. "You are the one that is good"
				* ~"You're good"
				* ~"I prefer you"
					* it can tend romantic
	* or a number of other ways
* Or by using these affirmation particles:
	* *Rri* (AFFIRM)
		* casual, can be rude
	* *Ae* (FORM.AFFIRM)
		* very formal and respectful
	* *Mun* (POT.AFFIRM)
		* 'it is possible' / 'I am able' / 'I should be able'
		* also formal
	* *Aia* (INTIM.AFFIRM)
		* more romantic or intimate
		* can be rude or immature (must never be used outside intimate/romantic/playful/teasing settings)
	* *Rie* (AFFIRM2)
		* 'I understand' / 'I see' / 'I get it'
		* very polite
	* *Oia* (POL.AFFIRM)
		* 'fine' / 'I guess so' / 'sure' / 'why not'
		* very polite general affirmative
	* *E* (okay)
		* 'okay'
		* usually can't directly be used for a type of affirmation, unless you say:
			* *E ue* (it is okay)
			* *Seka, e ue* (it is fine in that case / that way)
			* *Ee, seka ue* (alright, that's correct)
			* and so on...
* In most situations, you use:
	* *oia* or *mun*
	* for example:
		* *subite kamu yo?* :: do you want to eat?
			* *mun!* :: if possible, I'd love to / sure, I should be able to
			* *oia!* :: heck yes!
			* *rie!* :: I see that you clearly want me to, so I'll eat for you
		* *kamōesun ni yo?* :: how do you like my food?
			* *mun!* :: I'd have liked it, if I was able to
				* incredibly rude
			* *oia!* :: I don't get why anyone would dislike it
				* incredibly polite
			* *rie!* :: assuming you want me to, I'll say it is good
* In both examples, *rie!* sounds like a villain inner monologuing out loud (and is extremely sarcastic and rude, if you weren't being playful)
* And *mun!* functions as a:
	* `if [X] possible, then [X will happen]`
* ... which is why:
	* how is my food?
		* **if it is possible (to like it) - then I will like it**
			* seriously rude, like saying 'it's so horrendous I can't get myself to say that I like it'
	* do you want to eat?
		* **if it is possible (to eat) - then I will eat**
			* polite, like saying 'Why not? But let me make sure if I can'
 * ... and that is why the vibe changes a lot
* It is consistent and will require a little bit of internalisation
* Same rule for *rie*:
	* `[X] is understandable (for me)`
	* so, when you reply with *rie* to statements like:
		* *do you want to eat?*
		* *do you like my food?*
	* it naturally means:
		* **I see that you want me to eat (so I'll eat)**
		* **I see that you want me to like your food (so I'll like it)**
	* *rie* would be an expected answer to something like:
		* *sanōe momg tokamu* :: `3SG.F.POL-N.ACC SEQ-G.REVS PFV-eat.V`
			* ~"Because of her, we ate"
		* *rie*
			* ~"Oh, I see"
			* ~"I understand"
			* "Ahh"
	* or to someone teaching some topic
* As a question, these would obviously have similar logic:
	* *Rie yo?* :: (well), do you want me to? / should I?
	* ... and so on
* For example:
	* *Sanōe momg tokamu*
	* *Rie yo?*
		* should I understand why?
	* *Subite eanatenai yo?* (do you want to go out?)
	* *Rie yo?*
		* more literally, 'do you want me to?'
		* but pragmatically, 'do you want to go out?'
