## 1.1 Fundamentals
* Sentence structure is **SVO** only
* Language is **pro-drop**
	* *yarate kita* for "come to like you" is fine if you're looking at the person and saying it
* Root ending decides word type:
	* ′o-ending -> noun
	* ′bu-ending -> approximate modifier
	* any other ending -> verb (esp. ru/u) or modifier depending on context

## 1.2 Word types
* Each word type is marked:
	* *-o* for nouns
		* **hono**
		* **kamo**
		* **unso**
		* **sorao**
	* *-(r)u* for verbs or unmarked:
		* **kamu**
			* if the root ends in *-o*, inflect to *-u*
		* **kitaru**
			* only mark if ambiguous
	* unmarked for modifiers:
		* **ii kamo** -> good food
		* **kamonq kamo** -> inedible food
	* *-bu* for weak modifiers:
		* **iibu kamo** -> good-ish food
		* **kambu kamo** -> (kind of / sort of) edible food

### 1.2.1 Sentence examples
* *su kita zu* -> `1SG like 2SG`
	* "I like you"
* *su myo kita zu* -> `1SG QNT like 2SG`
	* "I like you a lot"
	* "I like you much"
* *zu myobu kita su* -> `2SG QNT-PROP like 1SG`
	* "You kind of like me a lot"

### 1.2.2 Modifying
* Use *te* and *tebu* as an infinitive and approximate infinitive:
	* *su yarate kita zu* -> `1SG come-INF like 2SG`
		* "I (have) come to like you"
	* *su yaratebu kita zu* -> `1SG come-PROP-INF like 2SG`
		* "I (have) kind of come to like you"

## 1.3 Negation and affirmation
* Use *ra* to negate and *ri* to affirm as well as emphasise:
	* *Kitari* -> `like-AFFIRM`
		* "(Yes), I really do like you"
		* "I genuinely like you"
		* "I actually like you"
	* *Kitara* -> `like-NEG`
		* "I don't like you"
	* *Ri, ii kamo* -> `AFFIRM good food.NM`
* Use *riyi* (AFFIRM2) or *raya* (NEG2) in noisy environments to distinguish between the two

## 1.4 Particle table
| Particle | IPA    | Function                       | Gloss   |
| -------- | ------ | ------------------------------ | ------- |
| **o**    | `o`    | Marks nouns                    | NM      |
| **(r)u** | `(ɾ)u` | Marks verbs if ambiguous       | V       |
| **bu**   | `bu`   | Marks approximate modification | PROP    |
| **te**   | `te`   | Description and adverb         | INF     |
| **ra**   | `ɾa`   | Negates                        | NEG     |
| **ri**   | `ɾi`   | Affirms and emphasises         | AFFIRM  |
| **riyi** | `ɾiji` | -                              | AFFIRM2 |
| **raya** | `ɾaja` | -                              | NEG2    |
* **NOTE:**
	* use the *-ute* form of the infinitive for marked verbs, especially for modals like *subute* **(want to)**
	* the noun marker *-o* does not strictly have to be used; it is often omitted when context or word order makes it clear
