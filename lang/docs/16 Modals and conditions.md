## 16.1 Modals
### 16.1.1 Base forms
| Particle | IPA     | English equivalent        | Gloss  |
| -------- | ------- | ------------------------- | ------ |
| subo     | `subo`  | *want, desire*            | desire |
| aniso    | `aɲiso` | *need, require, must*     | need   |
| naso     | `naso`  | *can, be able to*         | can    |
| ako      | `ako`   | *manage, succeed*         | manage |
| mero     | `meɺo`  | *attempt, try*            | try    |
| ŝire    | `ɕiɺe`  | *know how to, understand* | know   |

### 16.1.2 Verb forms
| Particle | IPA     | English equivalent                               | Gloss         |
| -------- | ------- | ------------------------------------------------ | ------------- |
| subu     | `subu`  | *want, desire*                                   | desire.V.PLAT |
| anisu    | `aɲisu` | *need, require*                                  | need.V.PLAT   |
| nasu     | `nasu`  | *let, allow, permit, see to it*                  | can.V.PLAT    |
| aku      | `aku`   | *be able to, make something work, succeed, come* | manage.V.PLAT |
| meru     | `meɺu`  | *give it a go, have a try*                       | try.V.PLAT    |
| ŝire    | `ɕiɺe`  | *know, understand*                               | know          |
* Examples:
	* *ri, sua subu ĉil* -> `AFF 1SG-AGT want.ACC water-DEF`
		* "Yes, I want the water"
	* *sua nasume sa′a kamu ĉiitalnan?* -> `1SG-AGT can.V.PLAT-REL 3SG.F-AGT eat.V.PLAT water-PRTV-DEF-1PL.POSS`
		* "I'll let her have some of the water of ours"
	* *sua merreu samizunlyą* -> `1SG-AGT try.IPFV.V.PLAT fish-2SG.POSS-that.DIST.MOD`
		* "I'll try that fish of yours"
	* *sua ŝire zuǫ hya?* -> `1SG-AGT know 2SG.ACC Q`
		* "Do I know you?"
	* *sua anisu zu* -> `1SG-AGT need.V.PLAT 2SG`
		* "I need you"
	* *sua subnyu sa* -> `1SG-AGT desire.V.ROM 3SG.F`
		* "I want her"

## 16.2 Conditionality
| Particle | IPA     | Gloss      |
| -------- | ------- | ---------- |
| ŝi      | `ɕi`    | COND       |
| į        | `ĩ`    | IRR.VLNK   |
| iyu      | `iju`   | IRR.V.ROM  |
| icu      | `ikʰu`  | IRR.V.PLAT |
| mhu      | `m̥͡mu` | IRR.N.ROM  |
| mho      | `m̥͡mo` | IRR.N.PLAT |
| pén     | `pɛn`   | IRR.NMLZ   |
* *mhu* and *mho* are rarely used, as they are often replaced by *pén* or their respective verbal forms *iyu* and *icu*

### 16.2.1 Irreal modals
| Particle | IPA      | English equivalent                     | Gloss             |
| -------- | -------- | -------------------------------------- | ----------------- |
| subį     | `subĩ`  | *should*                               | `desire.IRR.VLNK` |
| aniŝį   | `aɲiɕĩ` | *should have, should need, would need* | `need.IRR.VLNK`   |
| naŝį    | `naɕĩ`  | *could*                                | `can.IRR.VLNK`    |
| akį      | `akĩ`   | *would be able to*                     | `manage.IRR.VLNK` |
| merį     | `meɺĩ`  | *might*                                | `try.IRR.VLNK`    |
| ŝireį   | `ɕiɺeĩ` | *would know how to, would understand*  | `know.IRR.VLNK`   |
* Examples:
	* *sua subį kamu* -> `1SG-AGT desire.IRR.VLNK eat`
		* "I should eat"
	* *sua merį akų kamu samilsan* -> `1SG-AGT try.IRR.VLNK manage.VLNK eat.V.PLAT fish-DEF-3SG.F.POSS`
		* ~"I could try to eat that fish she prepared"

### 16.2.2 Conditionality
* Use *ŝi* for expressing conditionality
* It's just like the English 'if'
* Examples:
	* *sua kamiicu ŝi soa denhthu kamtteilnan!* -> `1SG-AGT eat.IRR.V.PLAT COND 3SG.M-AGT GET-PFV.V.PLAT eat.PROD-DEF-1PL.POSS`
		* "I would eat if he got our food!"
	* *yád, soa niriicu su ŝi a hatero soienín* -> `so 3SG.M-AGT see.IRR.V.PLAT 1SG COND AGT run 3SG.M-AUG-PER`
		* "Well, he would see me if I run past him"

### 16.2.3 Usage of other irreal particles
* The *iyu* particle is just the romantic equivalent of *icu*
	* *sua kitaiyu sa ŝi sa′a kitapaiĉiiyu su* -> `1SG-AGT like-IRR.V.ROM 3SG.F COND 3SG.F-AGT like-RECP-PFV.IRR.V.ROM 1SG`
		* "I would love her only if she had loved me back"

### 16.2.4 Temporally marked irreal markers
* For temporally marked irreal markers, just prepend *ù-* before the aspect or temporal marking
* So, "I would have eaten" would be something like:
	* *sua kamùthu* -> `1SG-AGT eat.IRR-PFV.V.PLAT`
* Romantic or platonic markers would go last and *iyu* or *icu* wouldn't be used
