## 13.1 Articles
| Article | IPA     | Gloss    |
| ------- | ------- | -------- |
| l(à)   | `l(ə)`  | DEF      |
| lén    | `lɛn`   | INDEF    |
| lö(s)  | `lɔ(s)` | INDEF.PL |
| lü     | `lʊ`    | DEF.PL   |
* *l* and *lén* are definite and indefinite articles
* The definite article has the following forms:
	* *-là*: consonant-final roots, no morpheme stacking
		* e.g., *hon* + *-l* -> *honlà* (the person)
	* *-íl*: only when multiple morphemes are used and it has to appear after a consonant
		* e.g., *kiuko* + *ii* + *nq* *l* -> *kiukiinqíl*
	* *-l*: regular form
		* e.g., *kiuko* + *ii* + *l* -> *kiukiil*
		* or *kiuko* + *l* -> *kiukol*
* Examples:
	* *honléna niru su* -> `person-INDEF-AGT see.V.PLAT 1SG`
		* "A person sees me"
	* *sua kamu samilén* -> `1SG-AGT eat.V.PLAT fish-INDEF`
		* "I eat any (kind of) fish"

### 13.1.1 Plurality
* The plural articles serve two functions: mark definiteness and plurality, as there is no overt plural marker
* If *lós* appears before another marker, then the *s* is omitted, unless the marker starts with *ó*
* Examples:
	* *honlós* -> `person-INDEF.PL`
		* "A / any people"
	* *hateru honlólla* -> `run.V.PLAT person-INDEF.PL-ALL`
		* "Run to a / any people / person"
	* *samilú* -> `fish-DEF.PL`
		* "The / those fishes"
	* *samilós* -> `fish-INDEF.PL`
		* "A / any fishes"

## 13.2 Determiners
| Determiner | IPA     | Gloss |
| ---------- | ------- | ----- |
| myo        | `m̥͡mo` | QNT   |
| rra        | `ɺa`    | NEG   |
* These are the base forms
* They are often used in their modifier form with *-ą*, other than 'rra'
* Examples:
	* *nigol* -> `cat-DEF`
		* "the cat"
	* *niglós* -> `cat-INDEF.PL`
		* "any / some cats"
	* *nigorra* -> `cat-NEG.MOD`
		* no cat
	* *nigmyą* -> `cat-QNT.MOD`
		* many cats
		* *myo no niglú* is also fine for 'many of the cats'
