## 2.1 Basic rules
* [kʰ] *c* is realised as [c͡ç] before [i ĩ ɪ]
* So, *ca cu ce co* are simply [kʰa kʰu kʰe kʰo], but *ci* is [c͡çi]
* The palatalised "h" sound *hy* [hʲ] is actually [çj]; but *hyi* is not a valid syllable, instead *hi* [j̊i] is simply used
* *th* is used instead of *tu* (*tu*->*tsu* now)
	* so, *korotu* -> *korothu*
* So, *katu* becomes *kathu*
