Vowels & Diacritics

Tawa uses a specialised set of diacritics to represent nasalisation. The current standard focuses on legibility and digital compatibility. However, do note that many dictionary semantic space entries will most likely keep the old writing system (e.g., ŝ instead of sh). Please do not be confused by this and use the 2nd revision.

Character Description Example
Á / á Peripheral vowels Áa sorala chien hya?
Ã / ã Nasal vowels Koryã?
Sh / sh Devoiced sibilant consonant Na′a earu shi wua earu
Zh / zh Voiced sibilant consonant Zhamunan ni ii'iil!
Ch / ch Affricate consonant Zua au chi hya?
